# 🏏 IPL 2026 Cricket Hub

Step into the world of IPL 2026! This is a responsive cricket website that brings live match simulation, points table tracking, player statistics, franchise achievements, and membership registration together in one fan-friendly hub — built entirely with HTML, CSS, JavaScript, and jQuery.

## ✨ Features

- **🔴 Live Match Simulation** — Follow simulated match action as it unfolds
- **📊 Points Table** — Real-time-style standings for every franchise
- **🧑‍💼 Player Statistics** — Dive into stats for players across teams
- **🏆 Franchise Achievements** — Explore each team's history and highlights
- **👥 Membership Registration** — Fans can sign up and join the community
- **📱 Fully Responsive** — Smooth experience on desktop, tablet, and mobile

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- jQuery

## 📁 Pages
